# 安行智构项目宣传网站 v5

纯静态产品展示网站，可直接部署到 GitHub Pages，不需要数据库或单独购买服务器。

## 本地查看

双击 `index.html` 即可浏览。发布到 GitHub Pages 后，电脑和手机都可以通过公开链接访问。

## GitHub Pages 部署

1. 新建 GitHub 仓库。
2. 将本目录内的全部文件上传到仓库 `main` 分支根目录。
3. 打开仓库 `Settings → Pages`。
4. `Source` 选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/ (root)`，保存。

通常等待几分钟后，GitHub Pages 页面会显示公开访问链接。后续可以继续修改并重新上传，网站会随之更新。

## 发布前确认

- 将页面中的 `anxing@xxx.edu.cn` 替换为正式联系邮箱。
- 确认人物照片、合作单位名称、应用证明和公章材料已获公开展示授权，并完成必要脱敏。
- 页面中的风险调节器已标为“交互演示”，实际项目展示时应替换为真实模型输出或经过确认的案例数据。

产品定位 → 国家命题与行业痛点 → 多源数据统一管理 → 关键路段风险推演 → 应急决策与方案比选 → 国产化技术底座 → 应用场景 → 工程验证 → 成果价值 → 团队合作。
